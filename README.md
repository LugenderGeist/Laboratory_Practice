## Лабораторный практикум по программированию микроконтроллера
Работа представляет из себя программирование микроконтролера STM32F429ZI на базе отладочной платы NUCLEO-144.
#### Задание
Собрать схему с включением 6-и светодиодов и 2-х кнопок. Первая кнопка задает количество одновременно включаемых светодиодов. Каждое нажатие второй кнопки включает следующее заданное количество светодиодов. Нажатие на вторую кнопку, после включения всех светодиодов, выключает их и процесс начинается сначала. В том случае, если первой кнопкой было задано одновременное включение 6-ти светодиодов, вторая кнопка просто включает все светодиоды и выключает их.

### Настройка регистров
Следующим этапом будет применение настроек регистров для используемых портов с помощью непосредственного взаимодействия с абсолютными адресами регистров. Для того, чтобы порты могли принимать и отправлять данные - на них необходимо включить тактирование. Включению тактирования на портах GPIOB и GPIOF соответствуют функции на одной шине AHB1, которая имеет адрес:  
*0x40023800*  
Следующей частью кода будет адрес настройки тактирования:  
*0x30*  
И последней частью будет будут биты, которые необходимо подать, чтобы включить тактирование для портов с литерами B и F. При условии, что для включения тактирования нужно подать 1 в двоичном коде, то из таблицы, приведенной на рисунке 4 видно, что это будут биты:  
*0x02*  
Для литеры В;  
*0x20*  
Для литеры F.  
*Таблица с информацией для включения тактирования*  
В результате для настройки тактирования используются следующие строки:  

**(uint32_t *)(0x40023800 + 0x30) |= 0x20 // тактирование для шины AHB1, для GPIOF*  
**(uint32_t *)(0x40023800 + 0x30) |= 0x02 // тактирование для шины AHB1, для GPIOB*  

Для дальнейшей настройки необходимо узнать адреса регистров, отвечающих за настройки литер GPIO:  
*Карта регистров GPIO*  
Зная этот адрес можно настроить для каждого пина:
- Вход или выход данных через функцию GPIOx_MODER (адрес - 0x00)  
- Скорость работы пинов через функцию GPIOx_OSPEEDR (адрес - 0x08)
- Подтяжку или стяжку через функцию GPIOx_PUPDR (адрес - 0x0C)  
- Тип выхода через функцию GPIOx_OTYPER (адрес - 0x04)  
Настройки для каждого пина в данной работе очень похожи. Для светодиодов задан вывод данных на порты, скорость работы для всех пинов задана средняя, подтяжек/стяжек нет, тип выхода не настраивается, так как он стоит по умолчанию на output push-pull. Пример для настройки пина F0 на вывод представлен ниже.  

**(uint32_t *)(0x40021400 + 0x00) |= 0x01      // вход или выход портов F*  
**(uint32_t *)(0x40021400 + 0x08) |= 0x01      // скорость работы портов F*  
**(uint32_t *)(0x40021400 + 0x0C) |= 0x00      // нет подтяжки/стяжки*  

Для включения и выключения светодиодов на них нужен подавать логический 0 или логическую 1. Как видно на рисунке 6, адрес функции, обеспечивающей подачу сигнала на пины - 0x14, для включения светодиода нужно подать 1 на соответствующий пин. Например, для включения светодиода, подключенного к пину F0 необходима следующая строка кода:  
**(uint32_t*)(0x40021400 + 0x14) |= 0x01*  
*Функция вывода данных на пины*
Для считывания кнопки нужно воспользоваться функцией получения данных с порта, ее адрес представлен на рисунке 7.  
*Функция получения данных с пина*  
Например, кнопка подключенная к порту B10 обрабатывается следующим образом (после логического И в строке записывается номер пина, с которого считываются данные):  
**(uint32_t *)(0x40020400 + 0x10) & 0x400*
После настройки пинов для работы с периферийными устройствами можно перейти к реализации программного кода.
