## Лабораторный практикум по программированию микроконтроллеров
Работа представляет из себя программирование микроконтролера STM32F429ZI на базе отладочной платы NUCLEO-144.
#### Задание
Собрать схему с включением 6-и светодиодов и 2-х кнопок. Первая кнопка задает количество одновременно включаемых светодиодов. Каждое нажатие второй кнопки включает следующее заданное количество светодиодов. Нажатие на вторую кнопку, после включения всех светодиодов, выключает их и процесс начинается сначала. В том случае, если первой кнопкой было задано одновременное включение 6-ти светодиодов, вторая кнопка просто включает все светодиоды и выключает их.
